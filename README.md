# SIAC — Sitio web

Sitio web de SIAC (Servicios Integrales en Administración de Condominio), construido con [Astro](https://astro.build).

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```

## Despliegue

Este proyecto se despliega automáticamente en GitHub Pages mediante GitHub Actions (`.github/workflows/deploy.yml`) en cada push a `main`.

Sitio publicado en: https://maicolart07.github.io/siac-web/
